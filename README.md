# Interactive CV · Victoria Carbonell Sánchez

Source code of my interactive CV, published with GitHub Pages at **[victoriacarbonell.github.io](https://victoriacarbonell.github.io)**.

The design follows the look of a technical drawing: a title block at the top, the career path laid out as production steps (OP 10 → OP 50) and collapsible sections for experience, projects, education and skills.

## Structure

```
├── index.html                  # The whole page: HTML, CSS and JavaScript
├── cv-victoria-carbonell.pdf   # Downloadable PDF version of the CV
├── icons/                      # Favicon and Apple touch icon
└── img/                        # Project screenshots and social preview image
```

## Tech

- Plain HTML, CSS and JavaScript in a single file, with no build step or dependencies
- Fonts from Google Fonts (Space Grotesk, Inter, JetBrains Mono)
- Spanish and English versions with an ES/EN switch
- Light and dark mode based on system settings
- Open Graph tags for link previews on LinkedIn and other platforms
